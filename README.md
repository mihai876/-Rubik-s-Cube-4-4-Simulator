 🧩 Rubik's Cube 4×4 Simulator — собери самую сложную версию

> «4×4 — больше кубиков, больше вызовов»

**Rubik's Cube 4×4 Simulator** — это набор консольных приложений для симуляции кубика Рубика размером 4×4×4.  
Программа позволяет вращать слои, перемешивать кубик, просматривать состояние всех граней и отслеживать ходы.

## 🚀 Особенности
- 🎲 Полная симуляция кубика 4×4 с 96 наклейками.
- 🔄 Вращение любого слоя: R, L, U, D, F, B (с указанием номера слоя).
- 🎨 Цветная визуализация в консоли.
- 🔀 Генерация случайных скрамблов (20-30 ходов).
- 📋 Отображение всех шести граней в виде развёртки.
- 🧩 Подсчёт ходов и возможность отмены (undo) — где реализовано.
- 💾 Сохранение/загрузка состояния (опционально).

## 🛠️ Установка и запуск

Для каждого языка — минимальные зависимости.

| Язык       | Зависимости                          | Команда запуска                         |
|------------|--------------------------------------|-----------------------------------------|
| Python     | стандартная библиотека               | `python rubik4.py`                      |
| Go         | стандартная библиотека               | `go run rubik4.go`                      |
| JavaScript | Node.js, `readline`                  | `node rubik4.js`                        |
| Java       | стандартная библиотека               | `javac Rubik4.java && java Rubik4`      |
| C#         | .NET (или mono)                      | `dotnet run`                            |
| Rust       | `rand`, `colored` (crates)           | `cargo run`                             |
| Ruby       | стандартная библиотека               | `ruby rubik4.rb`                        |
| PHP        | стандартная библиотека               | `php rubik4.php`                        |
